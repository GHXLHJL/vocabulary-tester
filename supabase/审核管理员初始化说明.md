# 审核管理员初始化说明

## 1. 执行 Migration

依次执行这两份 migration：

1. [20260819_review_queue_and_admin.sql](file:///e:/project/trae/study/supabase/migrations/20260819_review_queue_and_admin.sql)
2. [20260819_review_queue_rpc_hardening.sql](file:///e:/project/trae/study/supabase/migrations/20260819_review_queue_rpc_hardening.sql)

第二份会把审核相关能力切到 RPC 模式，并收紧直接表读写权限。

## 2. 生成管理员密钥哈希

在项目根目录执行：

```powershell
node "e:\project\trae\study\scripts\node\hash_admin_secret.js" "这里替换成你的管理员长密钥"
```

终端会输出一串 SHA-256 十六进制哈希。

## 3. 写入 Supabase

将上一步输出的哈希插入 `admin_config`：

```sql
insert into public.admin_config (secret_hash, is_active)
values ('上一步生成的哈希', true);
```

如果后续想更换密钥，可以先停用旧值，再插入新值：

```sql
update public.admin_config
set is_active = false
where is_active = true;

insert into public.admin_config (secret_hash, is_active)
values ('新的哈希', true);
```

## 4. 前端验证

完成后，打开工具设置：

1. 输入昵称
2. 在“管理员验证密钥”输入框中填入**原始长密钥**
3. 点击“验证”

验证成功后会直接进入审核界面。

## 5. 当前 RPC 职责

- `verify_admin_secret(text)`：校验管理员密钥
- `report_pending_answer(...)`：上报争议答案并自动累计出现次数
- `fetch_pending_reviews(text)`：管理员拉取待审核列表
- `review_pending_answer(...)`：管理员审批，并同步写入 `accepted_rules`
